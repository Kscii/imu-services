# 服务 1.1.0

新增单记录和跨记录的小时、日、周计步统计；按 GP2 步事件时间归入日历桶，保留有效覆盖和实验标记。统计接口共享并发限额，并按整个请求限制活动与步数区间数量。

推理库固定 1.0.0，分块 SB1 FC1 与整段 E7、GP2 算法及模型权重保持原指纹。HTTP v2、数据库 schema 2 不变。

67 项服务测试和 27 项库测试通过；实际容器的两种模式强杀恢复、镜像与源码一致性、空数据库离线安装均通过。工程验收详情见 reports/1.1.0/summary.md。

离线包包含两个仓库的源码快照、可复现的 wheel 和 sdist、CPU Docker 镜像、说明及校验摘要。下载后先验证外层 .sha256，再验证解包目录内 SHA256SUMS。

此版本不增加新的模型准确率证据。独立客户验收及生产部署尚未完成，GP2 胸前计步仍属实验功能。
